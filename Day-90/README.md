# The Most Dangerous Writing App

A distraction-free desktop writing application built using Python and Tkinter.

## About the Project

The Most Dangerous Writing App encourages users to keep writing without interruptions.

If the user stops typing for 5 seconds, all written content is automatically deleted!

## Features

- Clean and minimalist GUI.
- Real-time countdown timer.
- Automatically resets the timer when typing resumes.
- Deletes all text after 5 seconds of inactivity.
- Visual warning when the countdown reaches 2 seconds.
- Responsive writing area.

## Technologies Used

- Python
- Tkinter

## How to Run

1. Clone this repository.
2. Navigate to the project directory.
3. Run:

```bash
python main.py
```
