# Space Invaders Game

A classic Space Invaders arcade game built using Python and the Turtle graphics library as part of Angela Yu's 100 Days of Python course (Day 95).

## Features

- Player movement using keyboard controls.
- Shoot bullets to destroy incoming aliens.
- Three different alien types with different point values.
- Enemy movement with direction changes.
- Collision detection between bullets and aliens.
- Score tracking and a 3-life system.
- Win and Game Over screens.
- Restart the game without closing the window.

## Controls

| Key | Action |
|---|---|
| ← Left Arrow | Move left |
| → Right Arrow | Move right |
| Spacebar | Shoot |
| R | Restart after game ends |

## Technologies Used

- Python 3
- Turtle Graphics
- Object-Oriented Programming (OOP)
