# My Todo List

A simple, pastel-themed Todo List web application built with Python and Flask.

## Features

- Add new tasks
- Mark tasks as completed or undo completion
- Delete tasks
- Store tasks persistently using SQLite
- View total, remaining, and completed task counts
- Responsive layout with a soft pastel color palette

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- Jinja2

## Installation

1. Clone this repository.
2. Create and activate a virtual environment.
3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python3 main.py
   ```

5. Open `http://127.0.0.1:5000` in your browser.

The SQLite database and its table are created automatically when the application starts.
